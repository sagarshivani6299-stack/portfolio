# Shivani Sagar — Developer Portfolio

A responsive, motion-rich React portfolio with a Three.js / React Three Fiber hero scene, GSAP scroll reveals, and Lenis smooth scrolling.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Personalise before publishing

1. Update `src/data/portfolio.js` with your verified email, phone, GitHub and LinkedIn URLs.
2. Add your resume PDF to `public/Shivani-Sagar-Resume.pdf` and update the resume link in `Hero.jsx`.
3. Review experience dates and descriptions. Only keep dates and claims that are accurate.
4. Project links are included where supplied. Projects without a live URL intentionally show "Demo coming soon".
5. Do not publish admin demo passwords in a public portfolio. Add a safe demo account or remove admin-only links.

## Stack

React, Vite, Three.js, React Three Fiber, Drei, GSAP, Lenis, Lucide React, custom CSS.

## Deployment

Build with `npm run build`, then deploy the `dist` folder to Vercel, Netlify, or another static host.
